// 2. LLM CONNECTION: Sending a structured prompt
async function callLLM(systemPrompt, history, temp) {
  const response = await fetch("https://api.example.com/chat", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      temperature: temp, // 0 = factual, 1 = creative/risky
      messages: [
        // System instruction sets behavior:
        { role: "system", content: systemPrompt },
        // Full history gives the model "memory":
        ...history
      ]
    })
  });
  return (await response.json()).reply;
}

AI Basics Guide: How This App Works

Every concept below maps directly to the interactive lab and code above.

1. Rules vs. Language Models

In Rule-Based mode, getRuleBasedReply() searches KEYWORD_RULES for exact words and returns a hard-coded string. A Language Model (LLM) instead predicts the most likely next piece of text based on patterns learned from massive amounts of writing.

2. Prompts & System Instructions

Your typed message is the user prompt. The System Instruction (sent as { role: "system" } in callLanguageModel()) acts as a hidden job description that sets the bot's persona, tone, and rules before the chat begins.

3. Tokens & Limits

Models read and generate text in chunks called tokens—roughly 4 characters or ¾ of an English word each. estimateTokens() updates the live badge above because both your input history and the model's reply count toward token limits and API cost.

4. Context Across Turns

LLMs are stateless—they forget everything once a reply finishes. To create memory, handleSend() pushes each turn into chatHistory and resends the entire array on every request. Watch the dark JSON box grow with each message!

5. Hallucinations & Temperature

Because LLMs predict plausible-sounding text rather than checking a verified database, they can invent facts confidently. Raising the Temperature slider (toward 1.0) increases randomness and creativity—and also increases hallucination risk.

6. Next Steps & Running Locally

  • Run locally: Download this single .html file and double-click it to open in any browser—no install needed.
  • Give it a persona: Edit the System Instruction (e.g., "Speak like a friendly pirate").
  • Add knowledge (RAG): Paste your own notes/FAQs into the prompt so the bot answers from real facts.
  • Connect a real API: Move callLanguageModel() to a backend server so your API key stays secret.
